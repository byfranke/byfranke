# byFranke

Sou Frank, Engenheiro de Software. Atuo como Desenvolvedor de Produto com foco em Cybersecurity, SOC e Threat Intelligence. Sou o criador do projeto [Sheep](https://sheep.byfranke.com/). Tenho prática na integração de ambientes usando MISP, Splunk, Wazuh, DFIR IRIS, ELK Stack, n8n, Grafana e TheHive. Meu objetivo é unir minha base em gestão com o desenvolvimento de soluções aplicadas a segurança da informação.
